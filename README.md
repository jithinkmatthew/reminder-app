# Reminder Timer

A timer that reminds you to stay on task at set intervals until time's up.

Set a task and a duration, and the app counts down while playing a sound alert every X minutes (e.g. every 15 minutes) to keep you focused — with pause/resume support along the way.

## Features
- Set a task name and total duration
- Custom alert interval (default: every 15 minutes)
- Sound alerts generated in-browser (Web Audio API, no audio files)
- Pause and resume
- Progress bar and live countdown

## Usage
Open `index.html` in any browser — no build step, no dependencies.

## Deploy
Deployed as a static site on [Vercel](https://vercel.com).
